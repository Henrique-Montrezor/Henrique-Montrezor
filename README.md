## 🚀 Featured Project

### [myCDRecords](https://mycdrecords.duckdns.org)

A full-stack music discovery platform featuring personalized recommendations powered by a trained Machine Learning model.

**Architecture and technologies:**

- **Frontend:** React, TypeScript, and Vite
- **Backend:** Node.js, Express, and TypeScript
- **Database & Cache:** MySQL and Redis
- **Machine Learning:** Python and PyTorch
- **Infrastructure:** AWS EC2 and Docker
- **Integrations:** Spotify API and MusicBrainz

The project includes separate repositories for the frontend, backend, and ML component.

| Component | Repository |
|---|---|
| Frontend | [myCDRecords Client](https://github.com/Henrique-Montrezor/myCDrecords-Client) |
| Backend | [myCDRecords API](https://github.com/Henrique-Montrezor/myCDrecords-API) |
| Machine Learning | [myCDRecords ML](https://github.com/Henrique-Montrezor/myCDrecords-ml) |

🌐 **Live application:** [mycdrecords.duckdns.org](https://mycdrecords.duckdns.org)
